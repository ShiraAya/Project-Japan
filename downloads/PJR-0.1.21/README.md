Windows：下载 [download-PJR-0.1.21.cmd](https://github.com/ShiraAya/Project-Japan/raw/refs/heads/main/downloads/PJR-0.1.21/download-PJR-0.1.21.cmd)，双击运行。脚本会从此仓库下载、合并并核对 SHA-256，在脚本旁生成 `ProjectJapanRefined-0.1.21-alpha.jar`。脚本不会安装模组或运行 JAR。

有 Python 3 的 Windows、macOS、Linux：下载并运行 [download-PJR-0.1.21.py](https://github.com/ShiraAya/Project-Japan/raw/refs/heads/main/downloads/PJR-0.1.21/download-PJR-0.1.21.py)，无需第三方 Python 包。
