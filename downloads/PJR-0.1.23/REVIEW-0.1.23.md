# PJR 0.1.23-alpha 更新说明

安装包：49,816,835 字节（49.82 MB）；完全离线。Minecraft 1.20.1 / Forge 47.4.20 / Java 17。

## 本次修复

- 圈出的冈山近海方形地块是 PJR 数据分类错误，不是真实岛屿。GSI 海洋与内陆水域多边形重叠时，旧编译优先级覆盖了海洋类别。本版恢复这片海面，原有陆地像素全部保留，PJM 地图同步更新。
- 改善水库出口与河道周围坡面衔接。有峰湖截图窗口最大人工抬升从 33 降至 11 方块，御岳湖从 2 降至 0；原有水位和自然山势保留。
- 新增 33 条官方资料可追溯的河道，合计 389 河、221 湖。15 个原先无河道连接的湖泊新增至少一条连接；仍有 12 个零连接记录，逐湖说明区分自然特征、人工设施和未完成项。不会虚构河道强行连接。

## 安装

关闭游戏，替换旧 PJR，只保留一个版本。使用 PJM 时配套 1.3.10；其生产 Java 类与 1.3.9 完全一致，只同步地图数据和版本信息。新增地形需要新世界或未生成区块，已经生成的区块不会自动重塑。

比例仍是 X:Y:Z=0.5:0.5:0.5，东京站为原点；建造高度 -256 至 1999，富士山约 Y1882。

## 已验证与限制

严格离线构建、42 个 ABI 引用、当前核心网络 22,915,691 个断言、当前比例/海岸 10,734,635 个断言通过；启动和生成检查均未发出网络请求。原有 577 条河湖完整指纹一致；新增河道 21,317 个站点无干涸中心；221 湖的 2,542,361 个岸点无应急围堰。冈山改动瓦片逐像素验证 5,767,168 点，保留全部原干地。

出口仍有 8 对额外高度差 3 方块的孤立离散样点，不能保证所有小台阶消失。固定六地区共 150 区块的核心方块柱计算为 2.030 秒，引擎初始化 18.142 秒，仅代表此容器一次测量，不等于实机加载时间或 FPS。

本次没有运行图形 Minecraft、完整 ForgeGradle、光照或流体 tick。完整源码保留验证记录和复现工具；诊断图不是实机截图。
