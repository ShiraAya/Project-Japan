# PJR 0.1.24-alpha 验证范围

本版修复港区细长条与缺失高程边缘的地形断面。以下均针对 SHA-256 `71a64c622c6e08ef90447dec8a6e73e0fa2290293c6033f1e4bb1fd4f39b0428` 的 49,777,004 字节 JAR，或与其中生产字节码一致的 Java 核心。

- 明石附近截图坐标 `(-214483,60810)`、`(-214979,60288)`、`(-215695,59838)`、`(-215587,59738)`，每处半径 192 格逐格检查，共 994,955 对干地相邻关系，最大台阶 1 格。更大的 2800×2800 格区域以 4 格间距取样，原最大 15 格跳变降到 2 格。并非逐格检查了整个日本。
- 全部 11,324 张离线 DEM 瓦片：检查 605,175 处水平、竖直缺失边缘，包含瓦片接缝；原始高程文件和保留节点完全未改。小距离两侧采样连续，完整有效节点保持原值。涉及缺失边缘的瓦片 3,603 张。
- 港区遍查东京、大阪神户、名古屋、福冈、北九州、广岛、冈山、仙台、新潟、静冈、滨松、熊本、鹿儿岛、那霸、函馆和苫小牧 16 个窗口。清理 226 个窄长结构、73,060 个源陆地像素；4,184 张海岸瓦片逐项核对，变化仅为陆地→海面。562 个瓦片负载重建，包含距离场影响的邻瓦片。103 个打包资源变化，其他地理资产保持原样。
- 图一东京湾长条原宽端约 19.45 米，因此漏过旧 16 米阈值；它的 1,856 个源像素全部移除。71,721 个完全由精细海岸图集负责的清理样点都已是海面；1,339 个位于图集渐变边缘的样点单独记录，不声称全部转为海面。原 1,646 个海岸夹具没有被此轮清理改变。
- 在新地形上重新求解全部水系，389 河、221 湖的 610 个几何、水位及纵向剖面指纹与 0.1.23 相同。全国水系测试通过 22,915,691 个断言，包括 10,674,101 个纵向步进、270 个湖内区间、汇流连接、抽样湖岸与岛岸、方块列契约及并发确定性。
- 禁网安全管理器运行上述最终安装包，网络调用尝试为 0。固定六地区测试生成 150 个区块的 38,400 列，地形列约 2.423 秒，引擎载入约 17.094 秒。该计时来自共享容器，包含材质列查询，未测客户端帧率、区块光照或游戏完整启动。
- Java 17 核心和 WorldRuntime 重新编译；9 个 Forge 适配 class 逐字节保留，42 个核心 ABI 引用检查通过。包体低于 50,000,000 字节，ZIP 完整性通过。

完整日志保存在 docs/validation/ 中带 `0.1.24` 的文件。历史日志不是本轮新测试。完整 ForgeGradle、图形 Minecraft、ProtoChunk、光照及流体 tick 未运行；诊断图为实际生成高度绘制，不是实机截图。

修复只作用于新生成区块。PJM 1.3.11 只同步离线地图及版本信息，生产 Java/加载器代码沿用 1.3.10；其缓存和兼容性报告随 PJM 源码交付。
