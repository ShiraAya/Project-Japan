# PJSR 0.1.0-alpha 验证记录

2026-10-20。阶段：**真实小区域原型完成，尚非全国版或完整P1。**
基线 PJR 0.1.24；SR 1.0.15；三轴0.5。未修改 SR 仓库。

| 项目 | 结果 |
| --- | --- |
| 离线来源编译器 | 7个 Python用例通过；保留原始OSM子集、排除原因、哈希 |
| 道路核心计划 | 1,845项检查通过；14单元、总长1,071.08格；并行计划一致 |
| Forge 专用服新世界 | 661项检查通过；随机顺序269区块；568个中心线碰撞采样 |
| SR 原生接缝 | 13处共享端点的位置、切线、宽度、标线相位均通过 |
| 原生编辑操作 | 标线修改、连续分割、删除、删除后重新登记均通过 |
| 磁盘保存后重启 | 33项检查通过；最终14条原生记录完整NBT逐项一致；删除不恢复 |
| 原始 PJR 基础 | 原39个Java源文件仅改生成器入口；地形/水文二进制原样还原 |
| 发布构建 | Forge重混淆JAR；50,000,000字节预算；详见release.json |

本轮修复了 SR NBT净空值规范化、分割事务屏蔽普通回调，以及末端自动车道点
首次生成/读档初始化不一致的问题。分割覆盖在索引版本变化后补记；读取世界时再次核对。
自动末端点属于 SR 派生元数据，不单独视作玩家修改。

## 未通过验收范围（尚未测试或实现）

- 客户端视觉与实际驾驶、玩家工具UI全流程、多人同步、光影兼容。
- 强制断电/杀进程恢复；部分路段生成后复杂修改再探索的组合测试。
- 高速立交、隧道、路口、完整跨河水文样本及全国覆盖。
- 全国规模内存与长距离探索性能；本次结果不能外推全国版。
- 原PJR完整地理审计没有重新执行；其固定地形资源未修改。

当前14条路线计划常驻内存，只适合本试验包。整平尚无自然边坡，命中道路的区块暂时整体
避让植被。以上限制已写入安装说明，未将它们计作验收通过。
